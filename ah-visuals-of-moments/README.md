# AH Visuals of Moments

## Назначение проекта
**AH Visuals of Moments** — веб-платформа и галерея, объединяющая оригинальную авторскую фотографию, историю создания снимка, его географические координаты и физический объект — унисекс-футболку с соответствующим принтом.

Каждая фотография формирует отдельную историю и связывается с постоянным QR-кодом на печатной продукции.

---

## Технологический стек
- **Фреймворк:** Next.js (App Router)
- **Язык:** TypeScript
- **Стилизация:** Tailwind CSS
- **Линтинг:** ESLint
- **Шрифты:** `next/font` (Inter, Cormorant Garamond)

---

## Структура маршрутов
- `/` — Главная страница (Hero, концепция проекта, популярные моменты)
- `/collection` — Полная публичная сетка опубликованных историй
- `/moments/[slug]` — Страница конкретной истории, фотографии, локации и мокапов
- `/about` — Страница о проекте и философии бренда
- `/contact` — Контактная страница
- `not-found` — Кастомная страница 404 для несуществующих или черновых историй

## Локальные mock-данные
Все данные хранятся локально в [src/data/moments.ts](file:///c:/MyFEprojects/ah-visuals-of-moments/ah-visuals-of-moments/src/data/moments.ts) и строго типизированы интерфейсами в [src/types/moment.ts](file:///c:/MyFEprojects/ah-visuals-of-moments/ah-visuals-of-moments/src/types/moment.ts).

Объекты со статусом `draft` автоматически скрыты из публичной коллекции и вызывают `notFound()` при прямом переходе по их маршруту.

## Команды запуска
```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Проверка линтера
npm run lint

# Проверка типов TypeScript
npx tsc --noEmit

# Production сборка
npm run build

# Запуск production сервера
npm start
```
