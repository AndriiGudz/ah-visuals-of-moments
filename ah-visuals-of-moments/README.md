# AH Visuals of Moments

## Назначение проекта
**AH Visuals of Moments** — веб-платформа и минималистичная галерея, объединяющая авторскую фотографию, истоки снимка, его географические координаты и физический объект — унисекс-футболку с принтом.

Каждая фотография формирует отдельную историю и связывается с постоянным QR-кодом на печатной продукции.

---

## Технологический стек
- **Фреймворк:** Next.js 16 (App Router)
- **Язык:** TypeScript
- **Стилизация & Темы:** Tailwind CSS, `next-themes` (поддержка `system`, `light`, `dark` режимов)
- **Интернационализация (i18n):** Локальная система словарей и локализованная маршрутизация
- **Линтинг:** ESLint
- **Шрифты:** `next/font` (Inter, Cormorant Garamond)

---

## Локализация и маршрутизация
- **Поддерживаемые локали:** `en` (English — основной язык проекта) и `ru` (Русский). *(Немецкий язык `de` отложен на следующие этапы).*
- **Коренной маршрут `/`:** Определяет предпочтительный язык по cookie `NEXT_LOCALE` или заголовку `Accept-Language` и перенаправляет на соответствующую локаль (по умолчанию `/en`).

### Структура локализованных URL:
- `/[locale]` — Главная страница (Hero, концепция проекта, популярные моменты)
- `/[locale]/collection` — Полная публичная сетка опубликованных историй
- `/[locale]/moments/[slug]` — Страница конкретной истории, фотографии, локации и мокапов
- `/[locale]/about` — Страница о проекте и философии бренда
- `/[locale]/contact` — Контактная страница
- `not-found` — Локализованная кастомная страница 404 для несуществующих или черновых историй

## Поддержка тем (Light & Dark)
Проект поддерживает три режима оформления:
- `system` — автоматический выбор в соответствии с настройками ОС;
- `light` — светлая тема на основе тёплых оттенков слоновой кости (`#f9f8f3`), графитового текста и мягких границ;
- `dark` — тёмная тема на основе почти чёрного фона (`#0f0f11`) и светлого тёплого текста.

Переключение темы производится без вспышек неправильного цвета при загрузке благодаря `next-themes` и семантическим CSS-переменным в `src/app/globals.css`.

## Брендинг и графический логотип
Текстовый заголовок бренда в шапке сайта (`SiteHeader`) заменён на графический логотип в формате `.webp`:
- `public/brand/logo-on-dark.webp` — логотип для тёмной темы;
- `public/brand/logo-on-light.webp` — логотип для светлой темы.

Компонент `Logo.tsx` автоматически переключает версию логотипа при смене темы оформления и ведет на главную страницу текущей локали.

## Устройство локализованных данных Moment
Все моменты описываются интерфейсом `RawMoment` в `src/types/moment.ts` и хранятся в `src/data/moments.ts`.

- **Непереводимые данные:** `id`, `slug`, `status`, `createdAt`, `mainImage.src`, `mockups`, `availableColors.id/hex`, `availableSizes`, `videoUrl`, `externalPurchaseUrl`, `qrPath`, `coordinates`, `mapUrl`.
- **Локализованные данные:** Находятся в объекте `translations` для каждой локали (`title`, `shortDescription`, `story`, `seoTitle`, `seoDescription`, `dateLabel`, названия локаций и `alt`-тексты изображений).

### Функции получения данных:
- `getPublishedMoments(locale)` — возвращает список только опубликованных моментов для заданной локали.
- `getMomentBySlug(slug, locale)` — возвращает опубликованный момент по его `slug`.
- Объекты со статусом `draft` скрыты из коллекции, sitemap, `generateStaticParams` и вызывают `notFound()` при попытке прямого перехода.

## Переводы интерфейса
Словари интерфейса расположены в папке:
```text
src/i18n/
  config.ts            # Конфигурация локалей (en, ru)
  getDictionary.ts     # Функция получения словаря
  dictionaries/
    en.ts              # Английский словарь
    ru.ts              # Русский словарь
```

### Добавление новых переводов:
1. Задайте новые ключи в `src/i18n/dictionaries/en.ts`.
2. Переведите ключи в `src/i18n/dictionaries/ru.ts`.
3. Для контента историй добавьте перевод в объект `translations` нужного объекта в `src/data/moments.ts`.

## Переменные окружения
Создайте файл `.env.local` на основе `.env.example`:
```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```
В production укажите домен проекта (например, `https://ahvisuals.com`).
