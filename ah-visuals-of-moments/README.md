# AH Visuals of Moments

**AH Visuals of Moments** — веб-платформа и галерея авторской фотографии, объединяющая физический объект (унисекс-футболку с принтом) с историей создания кадра, его точными географическими координатами и постоянным QR-маршрутом.

Каждая фотография формирует отдельную историю («Moment») и наносится на унисекс-футболку. Все цветовые и размерные вариации одного дизайна объединены общей историей, страницей витрины и постоянным QR-идентификатором.

## Текущее состояние проекта (Status Summary)

Проект полностью переведен в **production-ready** состояние со следующими реализованными подсистемами:

1. **Content Layer (Git / TypeScript):**
   - Каталог историй хранится в `src/data/moments.ts`.
   - Поддержка двух языков интерфейса и историй: `en` (основной) и `ru`.
   - Постоянные короткие QR-маршруты `/q/[id]` с автоматическим определением языка браузера и редиректом на историю.
   - Независимость контента: статус активности товара в базе или нулевой остаток не скрывают саму историю и фотографии.

2. **Commerce Layer (Supabase / PostgreSQL — Single Source of Truth):**
   - База данных Supabase выступает единственным техническим источником правды.
   - Каталог продукции: коллекция **Summer 2019** (`REGULAR`), 3 товара (**MOM-001**, **MOM-002**, **MOM-003**), базовая цена **€50.00 EUR**.
   - Цветоразмерная матрица: 4 цвета (Deep Black, Muted Taupe, Warm Sand, Vintage Plum) × 4 размера (S, M, L, XL) = **48 production SKU**.
   - Связь слоев: `moment.productCode` (`MOM-001`) ⟷ `products.product_code` (неизменяемое поле на уровне триггера БД).

3. **Складская модель и атомарное резервирование:**
   - Прецизионный складской учет: физический остаток (`on_hand`), активный резерв (`reserved`) и вычисляемый остаток к продаже (`available = on_hand - reserved`).
   - Атомарное создание заказа (`rpc_create_order_with_reservation`) с блокировкой строк `FOR UPDATE` и строгой защитой от оверселлинга при параллельных запросах.
   - Полный журнал движений склада `stock_movements` (`RESERVE`, `RELEASE_RESERVATION`, `SHIP`, `RESTOCK`, `INITIAL_STOCK`).

4. **Быстрый заказ (Quick Order):**
   - Лаконичная форма покупки в 1 клик прямо со страницы истории.
   - Серверный расчет цены из базы данных (anti-tamper защита от клиентских манипуляций).
   - Поддержка постоянной идемпотентности (`idempotency_key` в таблице `orders`).
   - Фиксация заказа и отправка форматированного уведомления в Telegram администраторам (сбой Telegram изолирован и не отменяет оформление).

5. **Панель управления (/admin):**
   - Защищенный вход по паролю сессии (`/admin/login`).
   - Сводный дашборд с ключевыми метриками склада и заказов.
   - Разделы управления товарами, коллекциями, складом, заказами и журналом движений.
   - Управление жизненным циклом заказа: `NEW` → `CONFIRMED` → `PROCESSING` → `SHIPPED` (списание склада) → `COMPLETED` или `CANCELLED` (возврат резерва).

6. **Интеграция с Google Sheets:**
   - Операционный интерфейс менеджера для пакетного редактирования остатков и цен в EUR.
   - Двухфазный безопасный импорт (предпросмотр с валидацией перед применением в БД).
   - Защита системных колонок `reserved` и `available` от прямого перезаписывания.

## Переменные окружения

Создайте файл `.env.local` на основе шаблона [`.env.example`](.env.example):

| Переменная | Назначение | Область видимости |
| :--- | :--- | :--- |
| `NEXT_PUBLIC_SITE_URL` | Базовый адрес сайта (канонические URL, OpenGraph) | Клиент / Сервер |
| `NEXT_PUBLIC_ALLOW_INDEXING` | Индексация поисковиками (`true`/`false`) | Клиент / Сервер |
| `NEXT_PUBLIC_SUPABASE_URL` | URL инстанса Supabase | Клиент / Сервер |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Публичный анонимный ключ Supabase | Клиент / Сервер |
| `SUPABASE_SECRET_KEY` | Сервисный ключ Supabase (`service_role`) | **Только Сервер** |
| `ADMIN_PASSWORD` | Пароль доступа к административной панели | **Только Сервер** |
| `ADMIN_SESSION_SECRET` | Ключ шифрования сессий администратора (≥32 символа) | **Только Сервер** |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | Email сервисного аккаунта Google Cloud | **Только Сервер** |
| `GOOGLE_PRIVATE_KEY` | Приватный ключ Google Cloud (PEM) | **Только Сервер** |
| `GOOGLE_DEFAULT_SPREADSHEET_ID` | Fallback ID таблицы Google Sheets | **Только Сервер** |
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота для алертов о заказах | **Только Сервер** |
| `TELEGRAM_CHAT_ID` | ID чата / канала Telegram для алертов | **Только Сервер** |
| `RUN_HOSTED_INTEGRATION_TESTS` | Запуск тестов против hosted Supabase (`true`/`false`) | Тестовый запуск |

> [!CAUTION]
> Никогда не коммитьте файл `.env.local` и реальные секретные ключи в репозиторий Git.

## Команды разработки и контроля качества

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки (http://localhost:3000)
npm run dev

# Проверка строгой типизации TypeScript
npx tsc --noEmit

# Запуск автоматизированных тестов (изолированный in-memory mockState)
npm test

# Запуск тестов против боевой базы данных Supabase
RUN_HOSTED_INTEGRATION_TESTS=true npm test

# Проверка линтера (ESLint)
npm run lint

# Сборка production bundle (Next.js Turbopack)
npm run build

# Запуск собранного production сервера
npm start
```

## Что намеренно НЕ входит в скоуп (Intentionally Out of Scope)

Следующие функции сознательно исключены из текущей архитектуры и решаются операционно:
- **Онлайн-эквайринг:** Оплата банковскими картами через шлюзы (Stripe, PayPal) отсутствует; оплата согласовывается менеджером при подтверждении.
- **Корзина покупок:** Мульти-заказ отсутствует; каждый заказ оформляется на 1 позицию.
- **Личные кабинеты клиентов:** Регистрация покупателей не предусмотрена.
- **Интеграция со службами доставки:** Автоматический расчет тарифов и генерация накладных (DHL, Новая Почта) отсутствуют.
- **Email-уведомления клиентам:** Рассылка писем не настроена.
- **CMS для текстов историй:** Тексты и фотографии хранятся в репозитории кода.
- **Глобальный Edge Rate Limiting:** Защита от злоупотреблений делегирована инфраструктуре хостинга.
